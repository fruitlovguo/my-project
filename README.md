# my-project
Super-agent test project

## Super-agent 用法

1. 在本仓库的 Issue 中 `@a15915863728a-svg` 并描述你的需求，智能体会自动接收任务。
2. 收到请求后，智能体会回复确认（回执），然后基于 main 分支创建 agent/ 前缀的工作分支。
3. 完成修改后，智能体自动提交代码并发起 Pull Request，在原始 Issue 中回复进展链接。
4. 你只需在 PR 中进行 Code Review，确认无误后合并即可完成整个流程。

## 常见问题

**Q1: 怎么触发智能体？**
在任意 Issue 中 `@a15915863728a-svg` 并描述你的需求即可。智能体会自动识别任务并开始工作。

**Q2: 多久响应？**
通常在 Issue 发布后几秒到几分钟内，智能体会回复一条确认消息（回执），表示已接收任务。

**Q3: 在哪里看工单进展？**
智能体会在原始 Issue 中回复工作进展和 PR 链接，你可以直接在 Issue 中查看最新动态，也可以在 Pull Requests 页面查看代码变更详情。
